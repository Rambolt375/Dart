# AGENTS.md

## Overview
Flutter application showcasing basic Flutter widgets (`lib/widgets/`).

## Verification Commands
Run verification in this order before completing work:
1. `flutter analyze` - Static code analysis & linting
2. `flutter test` - Run Flutter widget and unit tests

## Architecture & Code Entrypoints
- `lib/main.dart` - Application entry point rendering `MenuPage`.
- `lib/widgets/` - Basic widget implementations (e.g., `container_widget.dart`, `counter_widget.dart`).
- `test/` - Test suite location.
